模块以 `BandObject.cs` 中的 `BandObject` 类为核心：该类继承自 `System.Windows.Forms.UserControl`，并显式实现 `IDeskBand`、`IDockingWindow`、`IInputObject`、`IObjectWithSite`、`IOleWindow`、`IPersistStream` 六个 COM 接口，作为所有 Explorer 工具栏的抽象基类。

- `Interop/` 子目录集中存放与 Shell/Rebar 交互的 P/Invoke 声明（`IDeskBand.cs`、`IDockingWindow.cs`、`IInputObject.cs`、`IObjectWithSite.cs`、`IOleWindow.cs`、`IPersistStream.cs`）以及对应的结构体/常量（`DESKBANDINFO`、`DBIM`、`DBIMF`、`REBARBANDINFO`、`RebarConstants`、`ExplorerGUIDs`、`MSG`、`POINT`、`_IServiceProvider`），形成对 Win32 Shell API 的纯托管映射层。
- `Attributes.cs` 定义 `BandObjectAttribute` 和 `BandObjectStyle`，用于在派生类上通过特性声明工具栏名称、样式（垂直/水平/任务栏工具栏）。`BandObject.SetSite` 中通过 `IInputObjectSite.QueryService` 探测 `IWebBrowserApp` 以获取当前 Explorer 实例，并调用虚方法 `OnExplorerAttached()` 通知派生类。
- `Dpi/` 子目录提供 DPI 感知能力：`DpiManager` 静态类封装 `GetDpiForMonitor`/`GetDpiForWindow` 等 Shcore/user32 API，`QTUtility` 封装 OS 版本判断；`DpiAwareControl`/`DpiAwareForm`/`DpiAwareUserControl` 是带 `NotifyDpiChanged` 回调的控件基类，配合 `IDpiAwareObject`/`IObjectWithDpi` 接口实现 DPI 变更传播。`BandObject` 内保留 `Dpi`/`Scaling`/`OnDpiChanged` 属性但默认未启用（相关代码被注释）。
- `BandObject.RebarBreakFixer` 是一个内部 `NativeWindow` 子类，通过子类化 Rebar 窗口拦截 `RB_SETBANDINFO`/`RB_DELETEBAND` 消息，修复 Windows 7 下 BREAK 样式丢失的已知问题。
- 依赖方向：`BandObject` → `Interop/*` + `Dpi/*` + `SHDocVw`（通过 `lib\interop\Interop.SHDocVw.dll` 引用）；`Dpi/*` 仅依赖 user32/shcore/gdi32 P/Invoke，不反向依赖 `BandObject`。
- 构建产物由 `BandObjectLib.csproj` 生成签名 DLL（使用 `..\QTTabBar Rebirth.snk`），并在 BeforeBuild 阶段通过 `Tools\GenerateInterop.ps1` 按需重新生成 `Interop.SHDocVw.dll` 与 `Interop.MSHTML.dll`。
