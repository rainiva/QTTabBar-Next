单项目 WinExe（SetHome.csproj，v4.8/x86），由 `SetHome.Main` 作为入口：先通过进程名去重保证单实例，再用 `WindowsPrincipal.IsInRole(Administrator)` 判断权限，非管理员时以 `runas` 自启动提升后退出自身。

主界面 `SetHomeForm` 继承自 `System.Windows.Forms.Form`，采用 Designer 生成的 `SetHomeForm.Designer.cs` + `SetHomeForm.resx` 资源文件组织 UI；窗体加载时读取 `HKCU\Software\QTTabBar\AutoSetHome` 开关，若启用则自动扫描当前目录的 `bin/java.exe|mvn.cmd|mvn.bat|mvnd.exe|ant.cmd|gradle.bat|runserver.cmd` 并调用对应处理函数完成一键配置。

核心逻辑集中在 `SetHomeForm` 内：
- 通过 `Registry.LocalMachine\SYSTEM\CurrentControlSet\Control\Session Manager\Environment` 读写 `JAVA_HOME/M2_HOME/MVND_HOME/ANT_HOME/GRADLE_HOME` 及 `PATH`；
- 使用 `RunCommand("setx", ...)` 持久化 PATH，并在 `UpdateEnvPath` 中尝试通过 `WM_SETTINGCHANGE`、`SHChangeNotify`、`RefreshPolicyEx` 广播刷新；
- `kill(oldPath, fileName)` 与 `getOldPath` 负责从 PATH 中剔除已失效或重复条目，再拼接 `%JAVA_HOME%\bin;...` 等占位符。

依赖方面仅引用 .NET Framework 标准库（System.Management、Microsoft.Win32、System.Drawing、System.Windows.Forms 等），不依赖 QTTabBar 程序集，属于独立可执行工具。
