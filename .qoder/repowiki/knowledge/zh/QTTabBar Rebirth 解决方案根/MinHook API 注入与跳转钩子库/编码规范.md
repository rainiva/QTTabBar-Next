- 所有公开 API 返回 MH_STATUS 枚举，错误码覆盖未初始化、已创建、不支持函数、内存不足、不可执行等状态，调用方统一据此判断。
- 共享状态（gHooks、gIsInitialized）读写均包裹 CriticalSection::ScopedLock，确保多线程安全。
- 修改目标函数入口前先用 ScopedThreadExclusive 挂起相关线程，再 VirtualProtect 改为 PAGE_EXECUTE_READWRITE 写入，最后恢复原保护属性。
- x86 与 x64 差异通过 #if defined _M_X64 / _M_IX86 分支处理，如 x64 使用 FF25 绝对跳转 + 独立 pTable，x86 直接写 E9 相对跳转。
- HDE 反汇编结果通过 hde_t 别名在 x86/x64 间透明切换，trampoline.cpp 中只出现单一 hde_disasm/hde_t 符号。
