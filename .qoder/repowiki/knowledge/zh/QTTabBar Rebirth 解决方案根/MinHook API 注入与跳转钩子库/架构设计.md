模块以 MinHook.h 暴露 C 风格 WINAPI 接口（MH_Initialize / MH_CreateHook / MH_EnableHook / MH_DisableHook），内部实现位于 src/ 下，按职责拆分为：
- hook.cpp：全局 HOOK_ENTRY 表 + Initialize/Uninitialize/CrateHook/EnableHook/DisableHook 主流程，负责线程安全（CriticalSection）、内存保护切换（VirtualProtect）以及相对/绝对跳转写入。
- trampoline.cpp：基于 HDE 反汇编器逐条扫描目标函数，复制并修补 CALL/JMP/Jcc/RIP 相对寻址，生成可执行回跳代码；x64 下额外分配 pTable 存放远跳转目标并通过 FF25 JMP [RIP+disp32] 间接访问。
- buffer.{h,cpp}：管理可执行代码区与数据区的临时缓冲，提供 AllocateCodeBuffer/AllocateDataBuffer/CommitBuffer/RollbackBuffer 原子提交语义。
- thread.{h,cpp}：ScopedThreadExclusive 在修改目标函数入口前挂起所有指向该地址的线程 IP，避免竞态。
- HDE32/HDE64：内嵌 x86/x64 指令解码子集，由 trampoline.cpp 通过 _M_IX86/_M_X64 条件编译选择对应头。
依赖方向：hook → {trampoline, buffer, thread, HDE*}，export.cpp 仅做 extern "C" 转发到 MinHook:: 命名空间下的同名函数，保持对外 ABI 稳定。
