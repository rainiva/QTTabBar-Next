文档按用途分层组织：
- `design/`：面向代码实现的设计说明，当前包含 WinUI 3 Fluent 风格 UI 升级方案（混合 WPF + GDI+ 路径），作为 Options 对话框与 Explorer Band 视觉改造的权威约束。
- `superpowers/plans/` 与 `superpowers/specs/`：成对存放由 Superpowers 子代理驱动的「计划」与对应「设计规格」，文件名以日期前缀区分版本，plans 描述可执行的任务步骤与验收命令，specs 记录问题背景、约束、风险与成功标准，二者共同构成 agentic worker 的执行输入。
- `archive/`：仅保留不可编译的历史实现（ExplorerManager.full.cs）及说明 README，明确与当前 Rebirth 分支中精简 stub 的关系，供移植时对照。
依赖方向单向：plans → specs → 源码；archive 不反向引用源码。
