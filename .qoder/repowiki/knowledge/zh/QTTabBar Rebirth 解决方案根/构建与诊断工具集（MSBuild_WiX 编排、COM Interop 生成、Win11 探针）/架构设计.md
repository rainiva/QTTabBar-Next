纯 PowerShell 脚本集合，按职责拆分为四个独立入口，依赖方向单向向外：
- `BuildInstaller.ps1` 作为顶层编排器，通过显式参数 → 环境变量 → vswhere 扫描 → 硬编码候选的回退链解析 MSBuild 与 WiX v3.11/3.14 的 `Wix.targets`；先调用 `GenerateInterop.ps1` 再生成 COM 互操作程序集，随后用 MSBuild `/m:1` 并行构建解决方案 `QTTabBar Rebirth.sln`（Mixed Platforms）及一个或两个 `.wixproj`（x86），支持 `-Project Installer|InstallerMini|Both`、`-Configuration Release|Debug`、`-DetectOnly` 等参数；针对 Defender 锁定 WiX cab 文件导致的 LGHT0001 错误实现指数退避重试。
- `GenerateInterop.ps1` 依赖 Windows SDK NETFX 4.8 Tools 中的 `TlbImp.exe`，将 `shdocvw.dll` 与 `mshtml.tlb` 反编译为 `lib\interop\Interop.SHDocVw.dll` / `Interop.MSHTML.dll`，供主项目引用。
- `Win11ProbeSession.ps1` + `Win11ProbeSession.Core.psm1` 构成探针会话：会话脚本导入 Core 模块后依次执行基线采集、Explorer 重启提示、托管切片抓取、原生 Trace 读取、诊断报告输出，并通过退出码传递结果；Core 模块以 `Export-ModuleMember` 暴露函数，内部使用 `[pscustomobject]` 管道数据对象串联阶段。
- 注册表文件 `QTTabBarLib.ExplorerProcessCaptor*.reg` 用于注入 Explorer 进程捕获逻辑。
各脚本之间仅由 `BuildInstaller.ps1` 顺序调用 `GenerateInterop.ps1`，彼此无相互依赖。
