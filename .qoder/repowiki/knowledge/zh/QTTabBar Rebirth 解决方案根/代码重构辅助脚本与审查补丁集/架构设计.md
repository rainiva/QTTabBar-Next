本目录是 .agents 工作区下的叶子模块，不包含可执行代码，仅由两类工件组成：
- Python 重构脚本（extract-*.py、split-config-models.py、unwrap-explorer-module.py、gen-explorer-access.py、patch-csproj.py）：通过硬编码绝对路径定位 QTTabBar/ 下的源文件，按行号区间或 #region 边界做文本切片，把大类的成员抽取到同命名空间下的 partial class 或嵌套 static helper，并同步改写调用方引用；gen-explorer-access.py 还扫描 ExplorerControllerModule 对 _owner 的访问，自动生成 QTTabBarClass.ExplorerAccess.cs 作为内部访问转发层。
- 审查与历史补丁（review-*.diff、702d948.diff、prev-qttabbarclass.cs、hook-extract.txt、settings-extract.txt）：记录每次重构的 diff 与人工审阅结果，供后续回溯。
依赖方向单向指向 QTTabBar/BandObjectLib 源码树，脚本之间无相互调用，各自独立运行。
