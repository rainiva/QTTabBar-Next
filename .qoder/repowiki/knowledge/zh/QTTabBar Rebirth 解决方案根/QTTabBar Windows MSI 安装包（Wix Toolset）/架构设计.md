模块由三个并列子目录组成：
- `Installer/`：完整版 MSI 项目（`Installer.wixproj`），通过 `<?foreach arch in x86;x64 ?>` 循环为同一份 wxs 生成双架构产物，同时包含所有内置插件（QTQuick、TurnOffRepeat、Memo、QTClock、QTWindowManager、QTFileTools、FolderTreeButton、QTViewModeButton、ActivateByMouseHover、ShowStatusBar 等）。
- `InstallerMini/`：精简版 MSI，仅保留核心 DLL 与 COM 注册，不含插件组件，但共享相同的 UI 模板与语言包。
- `InstallerHelper/`：C++ DLL（`CustomAction.cpp` + `InstallerHelper.def`，VCXPROJ 构建），作为 MSI Binary 被两个 wix 项目引用，提供 `HideBars`、`CloseAndReopen`、`CheckOldVersion`、`CloseAndReopenAndDeletePlugins`、`DeleteRegPlugins` 等 DllEntry，用于在安装/卸载序列中枚举 Explorer 窗口、发送自定义消息、读写 HKCU\Software\QTTabBar 并重启 Explorer。

依赖方向：wxs → InstallerHelper.dll（BinaryKey）→ Windows Shell/Registry API；wxs 还通过 `<netfx:NativeImage>` 调用 NGEN 预编译托管程序集。UI 层共用 `CustomWixUI_Minimal.wxs`，多语言字符串通过 `lang*.wxl` 注入。版本升级使用固定 `UpgradeCode`，通过 `RemoveExistingProducts` 与 `PreventDowngrading` 控制回退与替换。
