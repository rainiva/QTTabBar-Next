- 每个控制器都是 `public partial class QTTabBarClass` 下的 `internal class`，并通过只读字段 `private readonly QTTabBarClass _owner` 访问宿主，禁止直接继承或外部实例化。
- 构造函数统一采用 `(QTTabBarClass owner)` 形式，在构造时保存 `_owner` 引用，无其他初始化参数。
- COM 对象释放严格遵循 try/finally + `Marshal.ReleaseComObject` 模式，并在释放前记录 `QTUtility2.log("ReleaseComObject xxx")`。
- 异常路径统一使用 `QTUtility2.MakeErrorLog(exception)` 记录错误日志，避免抛出到宿主层。
- 对宿主 UI 的跨线程更新一律通过 `_owner.Invoke(...)` 封送到 UI 线程执行，如 `AsyncComplete_FolderTree` 中的回调。
