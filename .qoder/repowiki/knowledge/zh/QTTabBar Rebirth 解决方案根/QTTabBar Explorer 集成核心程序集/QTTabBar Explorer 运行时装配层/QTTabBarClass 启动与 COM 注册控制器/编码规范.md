- 控制器以 internal static class 或 internal class + owner 引用形式暴露，作为 QTTabBarClass 的单一职责拆分单元。
- COM 注册入口统一使用 Type.GUID.ToString("B") 生成带大括号的 GUID 字符串，再交由 ComRegistrationManager 完成注册/注销。
- 对 Registry 访问采用 using(RegistryKey ...) 块包裹，并在异常路径调用 QTUtility2.MakeErrorLog 记录错误而非向上抛出。
- UI 控件批量创建时使用 SuspendLayout/ResumeLayout 成对包裹，避免中间状态触发重绘。
