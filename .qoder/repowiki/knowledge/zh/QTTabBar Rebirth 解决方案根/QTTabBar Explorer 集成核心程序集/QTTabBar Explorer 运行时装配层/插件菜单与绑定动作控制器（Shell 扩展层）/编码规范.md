- 控制器类声明为 `public partial class QTTabBarClass` 下的 `internal class XxxController`，并通过构造函数注入 `_owner: QTTabBarClass` 而非继承或静态访问。
- 对外暴露的入口方法采用 `DoXxx(...)` 命名（如 `DoBindAction`、`DoFileTools`），由上层通过枚举或索引参数驱动分支逻辑。
- 对可能来自外部插件或用户输入的操作使用 try/catch 包裹并以 `PluginManager.HandlePluginException` / `QTUtility2.MakeErrorLog` 记录错误，保证宿主稳定。
- 涉及 UI 更新时先检查 `InvokeRequired`，再通过 `Invoke` 切换到 UI 线程执行（见 `FileToolsController.ShowMD5`）。
