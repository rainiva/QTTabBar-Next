- 每个控制器都是 `public partial class QTTabBarClass` 下的 `internal class`，通过构造函数注入 `_owner` 字段访问宿主，避免静态耦合。
- 对 Windows Shell 交互统一通过 `Interop.PInvoke.SendMessage` / `SetWindowPos` 等 P/Invoke 或 `WindowUtils` 包装完成，不在控制器内散落 Win32 常量。
- 涉及 COM 对象（`IShellBrowser`、`IShellView`、IDLWrapper）的方法使用 try/finally 块确保 `Marshal.ReleaseComObject` 与 `Marshal.FreeCoTaskMem` 释放。
- 长耗时或异步等待逻辑采用 `System.Windows.Forms.Timer` 配合自增计数器限制最大轮询次数，并在异常分支中记录日志后静默退出。
