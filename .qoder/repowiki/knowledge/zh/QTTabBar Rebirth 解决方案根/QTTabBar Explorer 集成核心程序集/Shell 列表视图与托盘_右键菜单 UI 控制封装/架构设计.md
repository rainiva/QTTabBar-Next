模块以 `AbstractListView` 抽象基类为中心，定义 GetHotItem / HitTest / SetFocus / RefreshSubDirTip 等统一操作接口，并通过两个具体实现覆盖不同 Shell 后端：
- `ExtendedSysListView32`：针对传统 SysListView32，通过重写 OnShellViewNotify 拦截 LVN.* / NM_CUSTOMDRAW 等 WM_NOTIFY 通知，并配合 NativeWindowController 捕获编辑框消息。
- `ExtendedItemsView`：针对 Windows 7+ ItemsView（UIAutomation），基于 AutomationElement 枚举项、计算热/焦点项矩形，适配 Content/Details/Thumbnail 等多种 ViewMode。
两者均继承自同目录外的 ExtendedListViewCommon（由 ClassDiagram1.cd 确认其存在），后者再派生自 AbstractListView，形成“抽象接口 → 通用逻辑 → 平台特定实现”的分层。

其余文件按职责划分且彼此独立：
- `ShellContextMenu.cs`：独立封装 IShellFolder + IContextMenu2，负责弹出单/多项目 Shell 右键菜单并转发 InvokeCommand；不依赖 ListView 体系。
- `TreeViewWrapper.cs`：包装 INameSpaceTreeControl，使用 NativeWindowController 拦截父窗口的 NM_CLICK / TVN_SELECTIONCHANGING 以及子树控件的 MBUTTONUP，将点击转换为 TreeViewClicked 事件。
- `TrayIcon.cs`：在独立后台线程上创建 NotifyIcon 与 ContextMenuStripEx，通过 ITaskbarList 将 Explorer 窗口加入任务栏预览，并提供最小化/恢复/关闭所有功能。
- `Toolbar.cs`：仅包含一个 Toolbar 枚举，标识 BandObject 中各工具栏槽位。

依赖方向单向向外：本模块调用 QTTabBarLib.Interop、BandObjectLib、ShellBrowserEx、IDLWrapper 等外部类型，自身不被其他 UI 控制流反向依赖。
