模块由一个 `partial class PluginServer`（实现 `IPluginServer`）与一个静态 `PluginManager` 组成，按职责拆分为多个 `.cs` 分部文件：
- `PluginServer.cs`：核心入口，持有 `_host(IPluginServerHost)`、`IShellBrowser`、本地化字符串字典 `dicLocalizingStrings`、已加载实例表 `dicPluginInstances`，并暴露一组以 `On*` 开头的事件转发方法，将宿主侧的 Explorer/Tab/Selection 等变化通过 `PluginEventArgs` 广播给插件。
- `PluginServer.Commands.cs`：集中处理 `Commands` 枚举的命令分发，统一通过 `_host` 调用导航、关闭标签、打开选项对话框等操作。
- `PluginServer.Lifetime.cs`：插件生命周期——`LoadStartupPlugins` 在构造时扫描 `PluginManager.PluginInformations` 并按 `PluginType`（Background / BackgroundMultiple / Static）分别加载；`RefreshPlugins` 同步启用状态并更新 `FilterPlugin`/`FilterCorePlugin`；`UnloadPluginInstance` + `RemoveEvents` 负责从所有事件委托中移除目标插件的订阅。
- `PluginServer.TabAccess.cs`：面向插件的标签页 API，返回 `ITab` 抽象（内部 `TabWrapper` 包装 `QTabItem`），封装浏览、历史、克隆、锁定、子文本等能力，并通过 `UpdateItem` 回调 ButtonBar 刷新 UI。
- `PluginManager.cs`：静态装配管理器，负责从注册表 `Plugins\Paths` 读取程序集路径、缓存 30s、对每个程序集反射解析 `PluginAttribute` 生成 `PluginInformation`，并通过 `Assembly.Load(byte[])` 加载到当前 AppDomain；同时包含 P1 安全加固逻辑（`ValidatePluginSource`、`HasTrustedSignature`、`IsWithinTrustedPluginDirectory`），默认保守策略仅告警，可通过 `Config.Security.BlockUntrustedPlugins` 阻断未签名/非受信任目录的插件。
依赖方向：`PluginServer` → `PluginManager`（发现/加载）→ `PluginAssembly`/`Plugin`/`PluginInformation`（运行时对象）→ 宿主 `IPluginServerHost`；`PluginServer` 不直接引用 UI 控件，全部通过 `_host` 或 `QTTabBarClass.TryCallButtonBar` 间接访问。
