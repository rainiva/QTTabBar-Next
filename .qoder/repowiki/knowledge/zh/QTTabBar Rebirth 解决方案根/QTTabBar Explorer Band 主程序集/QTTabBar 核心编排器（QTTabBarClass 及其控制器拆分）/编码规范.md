- 控制器通过构造函数注入一组窄 Host 接口（如 `IBindActionHost`、`IShutdownResourceHost`、`IExplorer*Host`），禁止在控制器中直接引用 `QTTabBarClass` 具体类型。
- `QTTabBarClass` 中以 `internal` 方法转发到对应控制器（如 `DoBindAction`、`DoFileTools`），对外保持单一入口，内部再委派到 `_xxxController`。
- 大型 partial 文件通过 `// Auto-merged by merge-partials.py (Batch N)` 或 `// ... extracted from ... (arch-batch...)` 注释标注来源批次，便于追踪拆分历史。
- Host 接口在 `ShellHosts.cs` 中以显式接口实现形式提供（`int IHookMessagePort.iSequential_WM_CLOSE { get => iSequential_WM_CLOSE; set => ... }`），使 `QTTabBarClass` 同时扮演宿主与实现者。
- Explorer 相关功能进一步拆成 `ExplorerXxxController` 子控制器，由 `ExplorerController` 通过延迟初始化属性组合，形成两级控制器层次。
