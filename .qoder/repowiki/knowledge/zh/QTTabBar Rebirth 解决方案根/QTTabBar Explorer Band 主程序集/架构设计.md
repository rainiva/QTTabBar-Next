本模块是 QTTabBar 的单一 .NET 程序集，按职责拆分为若干子目录并通过顶层类集中编排：
- Common/Interop/Multilang 提供对 Windows Shell COM、PropSystem、UIAutomation、MultiLanguage 等原生接口的 P/Invoke 包装，被所有上层子模块共享。
- ExplorerBrowser/ 封装 Explorer 浏览器控件与导航日志，供 TabBarBase/QTabControl 等 UI 层复用。
- OptionsDialog/FileRename 作为独立 WPF/WinForms 对话框，通过 core_services 中的 Config/SessionState 读写全局配置。
- QTTabBarClass.cs 及其 Controller 分部文件构成运行时门面，依赖 plugin_system 加载 IPluginServer，依赖 ipc_hook_infra 注入 HookLib 并分发 IPC 命令，再组合 tabbar_runtime 的各控制器完成 Band 生命周期。
- 顶层静态类（Config、SessionState、IconManager、TrayIcon、RebarController 等）充当进程级单例，使各子模块无需显式构造即可访问共享能力。
整体协作路径：BHO AutoLoader → PluginManager → QTTabBarClass（BandObject）→ 各 Controller → Common/Interop 调用 Shell API；跨实例协调走 core_services 的 WCF 命名管道。
