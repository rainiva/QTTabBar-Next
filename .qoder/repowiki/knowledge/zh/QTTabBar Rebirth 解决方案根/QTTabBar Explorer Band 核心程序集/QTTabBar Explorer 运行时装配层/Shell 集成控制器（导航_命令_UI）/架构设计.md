本模块由三个 `internal class` 组成，均作为 `QTTabBarClass` 的局部类片段（partial class），通过私有 `_owner` 引用访问宿主实例：
- `ShellNavigationController`：封装“上一级”导航，根据是否锁定当前标签页决定是否克隆并插入新标签，再通过 `PInvoke.SendMessage` 向 Explorer 发送 `0x111` (WM_COMMAND) + `0xa022` 消息触发系统导航。
- `ShellUiController`：集中处理与 Shell UI 相关的配置刷新，包括导航按钮工具栏的创建/停靠、多行标签布局切换 (`SetTabRowType`)、背景刷新 (`rebarController.RefreshBG`)、以及 XP 下通过 `ShowBrowserBar` 控制文件夹树和搜索栏的显隐；非 XP 时搜索栏走 `PATH_SEARCHFOLDER` 导航而非旧式浏览器栏。
- `ShellCommandController`：实现面向用户的 Shell 命令入口，如 `CreateNewFile`（在目标目录创建文件并通过 `IShellView.SelectItem` 进入编辑）、`OpenCmd`（启动 cmd.exe 并定位到当前路径）、以及基于 `System.Windows.Forms.Timer` 轮询注册表/剪贴板以同步微信/QQ 选择结果的辅助方法。
依赖方向单向指向 `QTTabBarClass` 暴露的公共成员（`CurrentTab`、`ExplorerHandle`、`ShellBrowser`、`tabControl1`、`toolStrip` 等），不反向引入外部模块；所有 P/Invoke 调用集中在 `Interop.PInvoke`、`WindowUtils` 及本类内声明的 User32 导入中。
