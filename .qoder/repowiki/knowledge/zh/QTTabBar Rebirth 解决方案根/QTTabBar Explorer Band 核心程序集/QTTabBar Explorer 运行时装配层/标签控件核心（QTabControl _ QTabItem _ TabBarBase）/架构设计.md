本模块由三个文件构成「容器-项-宿主基类」三层结构，依赖方向单向：TabBarBase → QTabControl → QTabItem。
- `QTabControl`（sealed class，继承 System.Windows.Forms.Control）是纯自绘标签容器，通过 `ControlStyles.UserPaint | OptimizedDoubleBuffer | AllPaintingInWmPaint | SupportsTransparentBackColor` 启用双缓冲与透明背景；内部用 `QTabCollection` 管理子项，支持单行/多行布局（`CalculateItemRectangle` / `CalculateItemRectangle_MultiRows`）、九宫格贴图拉伸（`tabImages` + `sizingMargin`）、关闭按钮/锁定图标/文件夹图标绘制，并通过 `QTabCancelEventHandler`、`QEventArgs` 等自定义事件向上层通知选中变更、关闭、拖拽、行数变化等。
- `QTabItem`（[Serializable] sealed class）是标签的数据载体，持有 CurrentPath / ImageKey / Comment / ToolTipText / Row / Edge 等属性，内部维护 back/forward 历史栈和分支列表，并提供静态 `TabFont` 同步设置标题与副标题字体；其 `ShellToolTip` 懒加载调用 `ShellMethods.GetShellInfoTipText` 获取 Shell 提示文本，`RefreshRectangle` 基于 Owner 的绘制环境计算 TitleTextSize/SubTitleTextSize 并更新 TabBounds。
- `TabBarBase`（abstract partial class，继承 BandObjectLib.BandObject）是所有标签栏宿主（主视图 QTTabBarClass、次视图 QTSecondViewBar 等）的共享基类，集中了上下文菜单项字段、导航按钮状态同步（`SyncTravelState`）、关闭历史写入（`AddToHistory`）、DPI 感知（`ComputeBandHeight` / `ResolveDpiScale` / `GetBandDpiScale` / `TryReadAppliedDpi`）以及 Rebar 高度计算等通用逻辑；它持有唯一的 `QTabControl tabControl1` 实例，作为容器与宿主的桥接点。
三者均依赖 `QTTabBarLib.Interop`、`QTPlugin`、`Config`、`QTUtility` 等外部子系统，但彼此之间不反向引用。
