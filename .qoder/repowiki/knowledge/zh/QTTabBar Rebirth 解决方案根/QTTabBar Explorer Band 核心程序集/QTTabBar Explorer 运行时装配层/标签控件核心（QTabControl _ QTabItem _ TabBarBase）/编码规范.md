- UI 相关布尔标志统一采用 `f` 前缀（如 fNeedPlusButton、fDrawCloseButton、fNowMouseIsOnCloseBtn），便于区分于普通字段。
- 对可能触发重绘的属性（如 Text、TabLocked、CurrentPath）在 setter 末尾调用 Owner.Refresh() 或 RefreshRectangle()，确保视图即时更新。
- 静态资源（StringFormat、Font、VisualStyleRenderer）使用 `[ThreadStatic]` 或 static 字段缓存并按需释放，避免重复分配。
- 对外暴露的事件使用自定义委托类型（QTabCancelEventHandler、QEventHandler、QEventArgs）而非原生 .NET 事件，以便支持取消操作与行号等扩展参数。
- DPI 与尺寸计算集中在 TabBarBase 的静态方法中（ComputeBandHeight、ResolveDpiScale、TryReadAppliedDpi），宿主仅调用而不重复实现。
