- 对外暴露的 UI 控件统一继承 AbstractListView，并以 virtual 方法提供空默认实现，子类按需重写，使上层可无差别持有任意列表后端。
- 通过自定义 NativeWindowController 订阅 MessageCaptured 事件来拦截 WM_NOTIFY / WM_KEYDOWN / 鼠标消息，而非重写 WndProc，从而在不替换宿主窗口的前提下增强行为。
- COM 对象（IShellFolder、IContextMenu2、IShellItem、ITaskbarList 等）一律在 try/finally 或 using 块中显式 Marshal.ReleaseComObject，并在日志中记录释放点。
- 跨线程访问 UI 组件（如 TrayIcon 的 ContextMenuStripEx）统一通过 Control.Invoke 或 lock + Monitor.Pulse/Wait 保证单线程 STA 语义。
- Windows 版本差异通过 OSDetector.IsXP 等条件分支处理，避免在运行时抛出异常作为控制流手段。
