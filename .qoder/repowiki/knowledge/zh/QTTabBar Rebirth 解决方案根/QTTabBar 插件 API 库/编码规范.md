- 每个公共接口以 I 前缀命名并以单独 .cs 文件存放，方法采用动词+名词的命令式风格（如 CreateTab、TryGetSelection、UpdateItem）。
- Windows Shell 相关 COM 接口、Win32 结构体与 DllImport 全部收敛在 QTPlugin.Interop 命名空间下，宿主与插件均通过该子命名空间访问底层。
- 可序列化/跨边界的配置值统一通过 TabBarOption + 分类型 enum（Boolean/String/Int/Color/Misc）的 SetValue/TryGetValue 重载进行存取，避免裸 Dictionary<int,object> 外泄。
- 可选本地化信息通过继承 LocalizedStringProvider 并在 PluginAttribute 构造中动态 Activator.CreateInstance 获取，失败时回退到默认错误文案。
