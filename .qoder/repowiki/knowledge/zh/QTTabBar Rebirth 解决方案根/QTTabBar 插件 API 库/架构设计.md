本模块是一个面向插件作者的纯接口程序集（OutputType=Library，TargetFramework=v4.8），由宿主进程加载后通过 COM/反射发现并实例化插件。

- 核心契约：`IPluginClient` 是插件必须实现的入口，宿主在 `Open(IPluginServer, IShellBrowser)` 时注入；`IPluginServer` 是宿主暴露给插件的回调与服务总线，包含 Explorer 状态事件（ExplorerStateChanged/NavigationComplete/SelectionChanged 等）以及创建标签页、管理分组、注册菜单项等命令式 API。
- 插件发现：通过 `PluginAttribute` 标记类并提供 `PluginType`，宿主扫描程序集元数据加载插件；`PluginType` 枚举区分按钮、过滤器、编码检测器等不同扩展点。
- Shell 互操作层：`Interop/` 子命名空间集中声明 Windows Shell COM 接口（IShellFolder、IShellView、IFolderView、IPersistFolder2 等）、Win32 结构体（POINT/RECT/SHELLDETAILS/STRRET/VARIANT）及 `PInvoke` 静态类中对 shell32.dll/shlwapi.dll 的 DllImport 封装，供 `IPluginClient.Open` 传入的 `IShellBrowser` 使用。
- 选项系统：`TabBarOption` 作为强类型字典包装，配合 `TabBar_Options_Boolean/String/Int/Color/Misc` 五个独立 enum 文件按值域拆分键空间，通过 `SetValue/TryGetValue` 泛型重载实现类型安全配置传递。
- 其他扩展点：`IBarButton`/`IBarDropButton`/`IBarCustomItem`/`IBarMultipleCustomItems` 定义工具栏按钮与自定义控件契约；`IFilter`/`IFilterCore`/`IEncodingDetector` 分别对应过滤与编码检测扩展点；`Commands`、`MenuType`、`EndCode`、`Address`、`ITab`、`DisplayStyle`、`PluginEventArgs`、`PluginEventHandler`、`LocalizedStringProvider` 等为配套常量、事件参数与本地化基类。
- 依赖方向：本程序集仅引用 System/System.Drawing/System.Windows.Forms，不依赖宿主代码；所有对 Windows Shell 的调用均经 `Interop/PInvoke` 单向桥接，保证插件侧无直接 P/Invoke 污染。
