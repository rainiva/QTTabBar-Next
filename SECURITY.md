## Reporting a Vulnerability

If you discover a security vulnerability in QTTabBar Rebirth, please report it
by opening a private security advisory on GitHub, or by emailing the maintainer
directly.

- **Do not** open a public issue for security vulnerabilities.
- Please include a description of the vulnerability, steps to reproduce, and
  the potential impact.
- You can expect an initial response within 72 hours.
- If the vulnerability is accepted, a fix will be prioritized and released in
  the next patch version.
- If the vulnerability is declined, you will receive an explanation of why.
